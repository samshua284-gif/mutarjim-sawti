# المترجم الصوتي دون اتصال

تطبيق أندرويد لمحادثة صوتية بين شخصين بأربع لغات — **العربية والإنجليزية والهندية والأردية** — يعمل **دون إنترنت إطلاقًا** (لا يملك التطبيق إذن شبكة أصلًا): السمع والترجمة والنطق كلها بنماذج داخل الجهاز.

## البنية

- **السمع**: Whisper-small (مكمّى) عبر Transformers.js في عامل ويب.
- **الترجمة**: NLLB-200-distilled-600M — ترجمة مباشرة بين اللغات الأربع كلها دون وسيط.
- **النطق**: أصوات Piper العصبية عبر sherpa-onnx 1.12.40 أصلًا في أندرويد — 7 أصوات: عربي (كريم، ذكر)، إنجليزي (أنثى/ذكر)، هندي (أنثى/ذكر)، أردي باكستاني (أنثى/ذكر)، مع منزلق سرعة نطق.
- **الغلاف**: WebView يقدّم الواجهة من أصول التطبيق بترويسات عزل كاملة، وجسر أصلي للنطق والنسخ.

## المحتوى

- `app/` — واجهة المحادثة وعاملا السمع والترجمة.
- `android/` — الغلاف الأصلي وسكربت البناء (`build-apk.sh`).
- `SPEC.md` — المواصفة الحية وقراراتها. `ASSETS.md` — جرد الأصول وأحجامها. `BUILD.md` — تقرير البناء والتحقق.

النماذج الثقيلة (~1.5GB) لا تُحفظ في هذا المستودع؛ تُجمَّع محليًا داخل الـAPK عند البناء (انظر `ASSETS.md` لمصادرها وأحجامها الدقيقة).

## الحالة

الإصدار 1.0 مبني وموقّع ومتحقق منه (حزمة `com.hilalsameer.voice`)، بانتظار اختبار القبول على الجهاز. البلوتوث بين هاتفين مرحلة ثانية مسجّلة في المواصفة.
